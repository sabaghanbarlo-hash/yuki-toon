Yuki Toon Studio

Paste a script. Yuki makes the cartoon video in your own voice.

1. Connect (one time)

The site starts the render on GitHub for you. It needs a GitHub access token that only lives in this browser. It is never sent anywhere except GitHub.

How do I get a token? (2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name: yuki-toon-site. Expiration: 90 days or longer.
  3. Repository access: Only select repositories → yuki-toon.
  4. Permissions → Repository permissions → Actions: Read and write. Nothing else.
  5. Generate the token, copy it, and paste it below.
