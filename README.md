# Yuki Toon (sandbox)

Test bed for a thick-outline cartoon explainer style (close-ups with big mouth reactions, picture/prop cuts, chart gags, side characters),
starring Yuki with the cloned voice. **Separate from `yuki-video`** - the main system is not touched. It only reads icons, fonts and `voice/ref.*` from it at run time.

Run: Actions -> *Make toon video (test)* -> Run workflow. The finished MP4 appears under Releases.

Script cues: `[face: shocked]` `[pose: shrug]` `[set: office]` `[with: boss]` `[text: Real Talk]` `[shot: closeup|medium|wide|prop|text]` `[sfx: gasp]` `[pause: 1]`
`[chart: x label | y label | up/down]` draws a hand-made graph that traces itself.
